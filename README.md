# Plan de chargement

Application web qui calcule et affiche le plan de chargement d'un camion de livraison à caisse fermée, puis guide le chargement étape par étape sur le quai. Projet personnel, développé avec Claude Code à partir des documents de `docs/`.

- Ce que fait l'application : `docs/cahier-fonctionnel.md`
- Comment elle est construite : `docs/cahier-technique.md`
- Maquette de référence : `docs/maquettes/`
- Mise en route du poste : `docs/installation.md`
- Avancement : `docs/sessions-claude-code.md`

Stack : Vue 3, TypeScript, Vite, Pinia, Supabase, Vitest, Playwright.
